# 隐私、联网与本地数据

浮音没有自己的账号系统，不要求音乐账号密码、Cookie 或 API 密钥。源码没有内置使用统计上传或广告功能；这不是对外部音乐播放器、第三方网站或未来修改版的隐私保证。

## 本机读取

- Windows 媒体会话中的来源应用、歌名、歌手、专辑、曲长、播放进度、播放/暂停状态和封面。
- 为识别本机来源而读取目标播放器进程和窗口标题、Windows 音频会话状态及可用的峰值。
- 音频检测不采集、保存或上传声音样本；它不做语音识别或音频指纹识曲。

## 在线歌词查询

根据匹配路径，歌名、歌手、曲长、专辑或播放器提供的歌曲 ID 等必要信息会发送到相应服务。接收方也会像普通网络请求一样看到来源 IP 等网络信息。

| 来源 | 当前代码使用的域名 | 用途 |
| --- | --- | --- |
| 网易云音乐 | music.163.com | 歌曲搜索、按 ID 查询歌词及逐字数据 |
| QQ 音乐 | u6.y.qq.com、c.y.qq.com | 歌曲匹配与歌词 |
| KuGou | mobileservice.kugou.com、lyrics.kugou.com | 匹配同录音并补充 KRC 字词时间 |
| LRCLIB | lrclib.net | 同步歌词获取与搜索回退 |
| GitHub | github.com 及其正常下载重定向域名 | 仅主动安装可选适配时下载固定上游组件 |

外部服务可能调整接口、限制访问或采用自己的隐私政策。本项目不替它们承诺数据保存规则，也不提供绕过账号或付费授权的功能。需要完全断网时，可使用已有缓存或本地 LRC，并由系统限制应用联网；当前软件没有单独的离线开关。

## 保存位置与权限

设置、歌词缓存和适配器暂存默认在 `%LOCALAPPDATA%\LumaLyrics`。创建桌面快捷方式和自启动均由用户在菜单主动操作；自启动还需明确确认。自启动使用当前用户启动文件夹，不是后台系统服务。

可选网易云适配在再次确认后写入所选播放器目录和组件数据目录，并可能配置 `BETTERNCM_PROFILE`。受保护目录可能请求管理员权限；拒绝仍可继续使用浮音其他功能。卸载规则见使用指南与源码。

## 分享问题

公开 Issue 可提供版本、歌曲示例与复现步骤。不要上传完整配置、歌词缓存、私人播放轨迹、访问凭据或未授权的音乐/歌词/封面。截图可能包含桌面和个人信息，请先自行检查。
