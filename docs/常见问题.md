# 常见问题与已知限制

## 启动后没有窗口

先看 Windows 托盘（含小箭头展开区域）是否已有浮音图标，双击恢复；游戏模式可能因暂停而隐藏。若提示已运行，请先从托盘退出旧版。确认完整解压，`Luma.exe` 与 `Luma.ps1`、`MenuTheme.xaml`、`CoverReader.dll`、图标等位于同一目录。

从源码下载的 ZIP 默认没有 EXE/DLL，需要运行 `scripts/Build.ps1`；普通使用者应下载 Releases 下的 Windows ZIP。

## 歌名识别不到或只显示播放器

确认客户端向 Windows 提供 SMTC 信息，开启相关设置后从播放器托盘完全退出并重开。尝试在“音乐来源”指定正在播放的应用。某些版本只提供音频流、不提供元数据或时间轴，此时浮音不能完整同步。浏览器网页播放器、多个并发音源和远程 Connect 会话也可能产生不同结果。

## 歌名正确但没有歌词

- 等待自动查询；网络失败会重试，已有缓存可继续显示。
- 歌名、歌手、曲长和录音版本共同参与匹配；现场版、剪辑版、翻唱、加速版可能没有对应歌词。
- 检查网络/代理能否访问歌词来源；程序不需要音乐账号密码或 Cookie。
- 可导入对应录音的本地 LRC。不要随意关闭系统安全软件来排查歌词网络问题。

## 句子对齐，但字词一会快一会慢

这是缺少或不准确的逐字数据时的已知限制。普通 LRC 只有整句开始时间，预测无法了解实际音节时长、句内休止和拖音。程序优先真实时间，并尝试按录音和原歌词行匹配补充 KRC；不会仅凭同名歌手的其他版本直接替换。

开发时《好久不见》《不要说话》部分句子已用公开响应做精度补充回放；这不代表所有版本均得到听感验证。“动力”157.14 秒版《第一滴泪》当时没有可确认的逐字来源，仍是预测。可以使用纯白/整句模式，或导入有对应时间的增强 LRC；不能声称预测已经精确同步。

## 整首歌词固定落后

用“歌词时间微调 → 提前”逐步调整。若整首领先则延后。切歌后检查是否需要重置，因为这是全局设置。随播放不断加大的偏差可能是错误录音、播放器速率或时间轴异常，不能只靠固定微调解决。

## 暂停后歌词仍动，或恢复后不同步

先确认运行的是最新版本，并完全退出过旧进程。Spotify 与网易云在部分环境下会延迟上报系统媒体状态；浮音增加本机音频会话和峰值辅助检测，但静音、长休止、其他同进程音频及陈旧时间轴仍可能影响判断。

Spotify Connect 到其他设备时关闭本机快速响应。网易云进度一直为 0 时参考使用指南的可选适配。反馈请附上 Windows/播放器/浮音版本、歌曲、发生时间和复现步骤，不要发完整私人播放记录。播放器更新时间轴的行为不能由浮音完全控制。

## 封面不显示或不清楚

封面来自播放器的公开缩略图。上游没有提供、接口超时或图片无效时显示渐变占位；低分辨率缩略图不会因为抗锯齿设置而恢复真实细节。换歌后等待一次元数据更新，确认其他媒体信息也正常。

## 亚克力看不到壁纸模糊

开启浮音“亚克力模糊”，再检查 Windows 的透明效果设置、显卡驱动、远程桌面环境。背景通透度只调着色，不代表系统模糊一定可用。“更多设置”里的背景引擎可帮助判断降级情况。缺少系统支持时会回退实色；离屏预览图不包含桌面的真实模糊采样。

## 颜色改了没变化

默认纯白模式不会随进度改变颜色；需要选逐字或整句模式。歌词颜色与进度条颜色相互独立。纯白当前句比下一句更亮，亮色壁纸下仍可能需要调整通透度或选用其他颜色。

## 重新获取没有删除错误缓存

“重新获取”不等于清空。可重新导入正确 LRC；需要完全清除时退出浮音，备份后删除 `%LOCALAPPDATA%\LumaLyrics\lyrics` 中对应缓存，或清理该目录后重新启动。全部清理会让其他歌曲也需要重新联网查询。不要把清理整个用户资料目录作为第一步。

## 可选适配安装失败

先完全退出网易云；该助手仅支持 64 位客户端。校验失败、已有其他版本同名文件、下载被阻止或目录无写权限都会停止安装。不要覆盖未知组件或绕过校验；可检查上游 BetterNCM / InfLink-rs 的兼容说明。浮音不会自动包含或升级这些外部组件。

## 验证范围

已执行本机 WPF 渲染与设置路径检查、媒体连接和封面解码、暂停/恢复记录回放、中英文歌词与匹配缓存测试。仓库的 Smoke 测试使用原创短句和构造时间，不上传真实播放日志。不同 Windows/播放器版本、QQ 音乐完整客户端播放链路、远程设备及所有歌词来源的持续可用性均不保证。
